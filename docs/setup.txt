# Setup Guide

This guide will help you set up the ORI application on your local development environment.

## Prerequisites

- PHP 8.1 or higher
- Composer
- Node.js and npm
- MySQL or compatible database
- Git
- (Optional) Electron for desktop version

## Installation Steps

### 1. Clone the Repository

```bash
git clone <repository-url>
cd ORI
```

### 2. Install PHP Dependencies

```bash
composer install
```

### 3. Install Node.js Dependencies

```bash
npm install
```

### 4. Environment Configuration

Copy the environment file and configure it:

```bash
cp .env.example .env
```

Edit `.env` with your database and application settings:

```env
APP_NAME="ORI"
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sea_service_db
DB_USERNAME=your_username
DB_PASSWORD=your_password

# For Electron desktop app
ELECTRON_APP=true
```

### 5. Generate Application Key

```bash
php artisan key:generate
```

### 6. Database Setup

Create a MySQL database and run migrations:

```bash
php artisan migrate
```

Optional: Seed the database with sample data:

```bash
php artisan db:seed
```

### 7. Build Frontend Assets

```bash
npm run dev
# or for production
npm run build
```

### 8. Start the Development Server

```bash
php artisan serve
```

The application will be available at `http://localhost:8000`

## Desktop Version Setup (Optional)

To run as a desktop application using Electron:

### Prerequisites
- Node.js installed
- Electron dependencies already included in package.json

### Build and Run
```bash
npm start
```

This will launch the application in an Electron window.

## Host-Based Configuration

The application supports different domains for different functionalities:
 
Update your hosts file or web server configuration accordingly.

## User Roles and Permissions

The system supports role-based access:

- **HR Admin**: Full access to all modules
- **HR Users/Operators**: Limited HR functions
- **MOC Operators**: Operations-focused access
- **Others**: Restricted access based on role

Create your first admin user through the registration process or directly in the database.

## Troubleshooting

### Common Issues

1. **Permission Errors**: Ensure proper file permissions for `storage/` and `bootstrap/cache/`
2. **Database Connection**: Verify database credentials in `.env`
3. **Assets Not Loading**: Run `npm run dev` to compile frontend assets
4. **Electron Issues**: Ensure Node.js version compatibility

### Logs

Check Laravel logs at `storage/logs/laravel.log` for backend errors.

### Testing

Run the test suite:

```bash
php artisan test
```
