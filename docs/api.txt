# API Reference

This document provides a comprehensive reference for all routes, controllers, and API endpoints in the Sea Service Testimonial & Vessel Tracker application.

## Route Structure

The application uses Laravel's web routes with session-based authentication. All routes are defined in `routes/web.php`.

## Authentication Routes

| Method | Route | Controller | Description |
|--------|-------|------------|-------------|
| GET | `/` | LoginController@login | Display login page |
| POST | `/Auth` | LoginController@auth | Process login authentication |
| GET | `/Logout` | LoginController@logout | Process logout |

## Vessel Management Routes

| Method | Route | Controller | Description |
|--------|-------|------------|-------------|
| GET | `/Vessels` | VesselController@index | List all vessels with search |

## Controller Details

### LoginController
Handles user authentication and session management.

**Key Methods:**
- `login()`: Returns login view
- `auth()`: Validates credentials, sets session, redirects based on host
- `logout()`: Clears session, logs audit trail

### VesselController
Manages vessel CRUD operations and operations view.

**Key Methods:**
- `index()`: Paginated vessel list with search functionality
- `create()`: Validates and stores new vessel
- `update()`: Updates existing vessel data
- `destroy()`: Soft deletes vessel
- `operations()`: Shows testimonials grouped by vessel

### EmployeeController
Handles crew member management.

**Key Methods:**
- `index()`: Main employee listing
- `deck_rating()`, `engineers()`, `captains()`: Role-based filtering
- Standard CRUD operations

### SeaServiceTestimonialController
Manages testimonial records.

**Key Methods:**
- `index()`: Testimonial listing with search
- `notifications()`: Dashboard with statistics
- Standard CRUD operations

### VesselAvailabilityController
Tracks vessel operational status.

**Key Methods:**
- `index()`: Status dashboard with filtering
- Auto-updates "TillNow" records on page load

### PDF Controllers
Handle document generation using FPDF library.

**Templates:**
- 5 main testimonial templates with alternate versions
- Availability reports
- Specialized boat reports

## Middleware and Security

- Session-based authentication required for all routes except login
- Role-based access control implemented in views
- CSRF protection on POST routes
- Input validation in controllers

## Request/Response Format

### Standard Response
All controllers return views with data arrays. No JSON API endpoints.

### Form Data
POST requests expect form-encoded data matching model attributes.

### File Uploads
Supported for images and documents in vessel/generator forms.

## Error Handling

- Laravel's built-in validation with redirect back on errors
- Custom error messages in controllers
- Database transaction rollback on failures
- User-friendly error pages

## Performance Considerations

- Paginated results for large datasets
- Eager loading for related data
- Database indexes on search fields
- Caching for frequently accessed data
