### Naming Conventions

**Controllers:**
- PascalCase class names
- Descriptive method names
- Resourceful routing where applicable

**Models:**
- Singular nouns
- PascalCase
- Relationships defined with proper naming

**Views:**
- kebab-case filenames
- Consistent with route names
- Component-based organization

**Database:**
- snake_case table names
- Foreign keys: `table_id`
- Indexes on searchable columns

## Controller Best Practices

### Structure

```php
<?php

namespace App\Http\Controllers;

use App\Models\Vessel;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Validator;

class VesselController extends Controller
{
    public function index(Request $request)
    {
        $query = Vessel::query();

        // Search functionality
        if ($request->has('search')) {
            $search = $request->search;
            $query->where('VesselName', 'LIKE', "%{$search}%")
                  ->orWhere('ImoNumber', 'LIKE', "%{$search}%");
        }

        $vessels = $query->paginate(15);

        return view('Pages.Vessels', compact('vessels'));
    }

    public function create(Request $request)
    {
        $validator = Validator::make($request->all(), [
            'VesselName' => 'required|string|max:255',
            'ImoNumber' => 'required|string|unique:vessels_vessel_information',
            'Company' => 'required|string',
        ]);

        if ($validator->fails()) {
            return redirect()->back()
                           ->withErrors($validator)
                           ->withInput();
        }

        Vessel::create($request->all());

        return redirect()->route('Vessels')->with('success', 'Vessel created successfully');
    }

    public function update(Request $request, $id)
    {
        $vessel = Vessel::findOrFail($id);

        $vessel->update($request->all());

        return redirect()->route('Vessels')->with('success', 'Vessel updated successfully');
    }

    public function destroy($id)
    {
        $vessel = Vessel::findOrFail($id);
        $vessel->delete();

        return redirect()->route('Vessels')->with('success', 'Vessel deleted successfully');
    }
}
```

### Validation Rules

```php
        'Company' => 'required|string',
        'Flag' => 'nullable|string',
        'PortOfRegistry' => 'nullable|string',
    ];
}
```

## Error Handling

### Global Exception Handler

```php
// app/Exceptions/Handler.php
public function render($request, Throwable $exception)
{
    if ($exception instanceof ModelNotFoundException) {
        return response()->view('errors.404', [], 404);
    }

    if ($exception instanceof AuthorizationException) {
        return response()->view('errors.403', [], 403);
    }

    return parent::render($request, $exception);
}
```

## Performance Optimization

### N+1 Query Prevention

```php
// Bad
$vessels = Vessel::all();
foreach ($vessels as $vessel) {
    echo $vessel->company->name;
}

// Good
$vessels = Vessel::with('company')->get();
foreach ($vessels as $vessel) {
    echo $vessel->company->name;
}
```

### Caching

```php
// Cache expensive operations
$companies = Cache::remember('companies', 3600, function () {
    return Company::all();
});
```

### Database Optimization

```sql
-- Add composite indexes
CREATE INDEX idx_vessel_search ON vessels_vessel_information (VesselName, ImoNumber, CallSign, Flag);
CREATE INDEX idx_availability_status ON vessel_availabilities (Status, StartDate, EndDate);
```

## Security Best Practices

### Input Validation

Always validate user input:

```php
$request->validate([
    'email' => 'required|email',
    'password' => 'required|min:8',
]);
```

### Mass Assignment Protection

Use fillable properties:

```php
protected $fillable = ['name', 'email'];
protected $guarded = []; // Never use this
```

### SQL Injection Prevention

Use Eloquent or parameterized queries:

```php
// Good
User::where('email', $email)->first();

// Bad
DB::select("SELECT * FROM users WHERE email = '$email'");
```

### XSS Protection

Escape output in Blade:

```blade
{{ $user->name }} <!-- Escaped -->
{!! $user->bio !!} <!-- Not escaped, use with caution -->
```
