# Deployment Guide

This guide covers deploying the Sea Service Testimonial & Vessel Tracker application to production environments.

## Prerequisites

- Web server (Apache/Nginx)
- PHP 8.1+ with required extensions
- MySQL 5.7+ or MariaDB
- SSL certificate
- Domain configuration

## Server Requirements

### PHP Extensions
```
- pdo_mysql
- mbstring
- xml
- curl
- zip
- gd
- bcmath
- json
```

### Web Server Configuration

#### Apache (.htaccess)
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteRule ^(.*)$ public/index.php [QSA,L]
</IfModule>
```

#### Nginx
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/ori/public;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.ht {
        deny all;
    }
}
```

## Deployment Steps

### 1. Code Deployment

```bash
# Clone repository
git clone <repository-url> /var/www/ori
cd /var/www/ori

# Install dependencies
composer install --no-dev --optimize-autoloader
npm install
npm run build
```

### 2. Environment Configuration

```bash
cp .env.example .env
```

Edit `.env` for production:

```env
APP_NAME="Sea Service Testimonial"
APP_ENV=production
APP_KEY=base64:generated-key
APP_DEBUG=false
APP_URL=https://your-domain.com

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=ori_production
DB_USERNAME=production_user
DB_PASSWORD=secure_password

# Security
SESSION_SECURE_COOKIE=true
SANCTUM_STATEFUL_DOMAINS=your-domain.com
```

Generate application key:
```bash
php artisan key:generate
```

### 3. Database Setup

```bash
# Create database
mysql -u root -p
CREATE DATABASE ori_production;
GRANT ALL PRIVILEGES ON ori_production.* TO 'production_user'@'localhost' IDENTIFIED BY 'secure_password';
FLUSH PRIVILEGES;
EXIT;

# Run migrations
php artisan migrate --seed
```

### 4. File Permissions

```bash
# Set proper ownership
chown -R www-data:www-data /var/www/ori
chmod -R 755 /var/www/ori/storage
chmod -R 755 /var/www/ori/bootstrap/cache
```

### 5. Storage Link

```bash
php artisan storage:link
```

### 6. Caching and Optimization

```bash
# Cache configuration
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Optimize autoloader
composer dump-autoload --optimize
```

## SSL Configuration

### Let's Encrypt (Recommended)

```bash
# Install certbot
sudo apt install certbot python3-certbot-apache

# Generate certificate
sudo certbot --apache -d your-domain.com -d www.your-domain.com
```

### Manual SSL

Update Nginx configuration:
```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /path/to/certificate.crt;
    ssl_certificate_key /path/to/private.key;

    # ... rest of config
}
```

## Domain Configuration

### Host-Based Routing

Configure domains for different modules:

```
seaservice.your-domain.com → Sea Service Testimonial
vesseltracker.your-domain.com → Vessel Tracker
```

Apache virtual hosts:
```apache
<VirtualHost *:80>
    ServerName seaservice.your-domain.com
    DocumentRoot /var/www/ori/public
    # ... SSL and other config
</VirtualHost>

<VirtualHost *:80>
    ServerName vesseltracker.your-domain.com
    DocumentRoot /var/www/ori/public
    # ... SSL and other config
</VirtualHost>
```

## Backup Strategy

### Database Backup

```bash
# Daily backup script
mysqldump -u production_user -p ori_production > backup_$(date +%Y%m%d).sql
```

### File Backup

```bash
# Backup uploads and config
tar -czf files_backup_$(date +%Y%m%d).tar.gz storage/ .env
```

### Automated Backups

Set up cron jobs:
```bash
# Daily at 2 AM
0 2 * * * /path/to/backup-script.sh
```

## Troubleshooting

### Common Issues

1. **Permission Denied**: Check file ownership and permissions
2. **White Screen**: Check PHP error logs, ensure APP_KEY is set
3. **Database Connection**: Verify credentials and network access
4. **Assets Not Loading**: Run `npm run build` and check public/build/

### Debug Mode

Temporarily enable debug for troubleshooting:
```env
APP_DEBUG=true
```

Remember to disable in production.

### Log Analysis

```bash
# Check Laravel logs
tail -f storage/logs/laravel.log

# Check web server logs
tail -f /var/log/apache2/error.log
# or
tail -f /var/log/nginx/error.log
```
